## Project Overview

This project analyses a video game sales dataset (`vgsales.csv`) 
to support retail strategy decisions for an upcoming Autumn season.  
The analysis was completed using Python in a Jupyter Notebook.

## Research Questions

1. What are the **top 5 games** by global sales?
2. What is the **distribution** of the most popular 4 game genres?
3. Do **older games (≤2006)** have a higher median EU sales than newer games?
4. What are the **3 most common developers** in the dataset?
